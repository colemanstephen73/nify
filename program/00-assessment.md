# 00 · Baseline Skills Check

**When:** weekend 1 (baseline), then at the end of each phase (the lighter
weekends: weeks 4, 8 and 12, or whenever you think the exit criteria are met).
**How long:** you don't run a test. You **watch** during normal runs and games, and score afterwards.
**Your child never sees scores as "marks".** To them it's just driving and games. [Synthesis]

## The scale (1–3)

| Score | Meaning | Look for… |
|---|---|---|
| **1 · Not yet** | Hasn't shown it, or only by luck | Needs you to remind them every time |
| **2 · Sometimes** | Shows it on some laps, or with a cue | Good on easy bits, drops it on hard bits |
| **3 · Every time** | Does it on their own, most laps, on **two different days** | Looks automatic, no reminding |

**Rule:** a skill is only a **3** if you've seen it on **2 different track days**.
One great day can be luck. [Synthesis]

Score only what you actually saw. Leave Phase 2 and 3 items blank at baseline
if you don't see them. That's expected.

## After each check

1. Copy the scores into the tracker (`session_type` = `assessment`, `drill` = the A-number).
2. Check the exit criteria in `01-phase-plan.md`.
3. **Exit criteria met → next phase.** Not met → stay, and pick the cards for the skills scoring 1–2.
4. If A29 (fun) is under 3: **slow down.** Use more TR-00 Fun Only days and fewer drills. Fun beats the plan, every time.
